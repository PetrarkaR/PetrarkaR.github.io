# Square-root microprocessor lab

User explicitly requested replacing the adder with the VHDL microprocessor and
square-root program, showing stages and a run button. Keep the rest of the site.

Source: PetrarkaR/Projektovanje-VLSI, commit
17b0385ccd2a95c651c14b3190fbfc2d8d01ff23, z4/{controller,ALU,DEFS,pc,IR,MAR,
microcontroller,ROM_squareroot}.vhd and square.c.

Design: model the existing sequential controller I1 → I2 → I3 → I4..I10,
8-bit PC/IR/MAR/data, 9-bit accumulator (8 data + F), zero flag and 256×16 RAM.
ROM-to-RAM startup and button interrupts are preloaded for the browser; the
program starts at the calculation interrupt vector 04. No invented pipeline.
A corrected ROM translates square.c's eight radix-4 iterations to real ISA
instructions and original scratch addresses. Explain adaptation in UI/source notes.
The original ROM produces 11 for 123 but 116 for 65535 in instruction-level
checking (expected 255); do not pretend it is the working ROM unchanged.
